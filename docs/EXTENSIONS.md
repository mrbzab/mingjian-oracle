# 紫微与奇门扩展

## 紫微

通过 mingyu-core 0.2.1 的 buildAstrolabeFromInput 调用 iztro 2.6.1。沿用命笺已经解析的 clockDate（含历史时区和可选真太阳时），转为公历日期与 0–12 时辰索引；晚子时索引为 12。不重复纠正时区或经度。

须提供出生时刻与男女口径；未知资料不代填。支持通行与中州口径；农历正月初一换年、虚岁按农历年、闰月前后半月修正，晚子时随原换日选择。紫微年界不沿用八字立春规则。

输出本命十二宫、主辅杂曜、星曜亮度、生年四化、身宫、命主身主、五行局及大限虚岁区间。桌面按地支显示环形盘，窄屏转换为可读宫位卡片。未实现流年四化、合盘、宫干飞化交互；提示词明确范围。

## 奇门

独立的起局时间与问题，不使用出生资料。固定 UTC+8，以 Temporal 严格校验 1901–2099 年日期后创建绝对时间。显式设置命语 TimeManager 为 UTC+8；转盘、时家、拆补法。

输出阴阳遁、局数、值符值使、节气与定局节气、旬空驿马、九宫天地人神盘及格局关系。九宫顺序 4/9/2、3/5/7、8/1/6，保持南上北下。保留随行天禽星及随行干，不将中宫寄宫隐藏。

上游附加 seasonality 使用本机 Date 构造，其衍生背景未纳入结果；不输出方位建议、应期估计或数值吉凶。跨设备时区测试针对实际交付的盘面快照。

## 数据与许可

按用户点击动态加载算法。输入及生成材料留在浏览器内存；不调用 AI 或上传，提示词可编辑复制。输入变化后提示上次结果过期并禁止复制。

第三方许可随 public/THIRD-PARTY-NOTICES.txt 交付。测试见 tests/metaphysics.test.mjs，覆盖未知资料、两种紫微流派、晚子时、历史夏令时、真太阳时跨日、九宫与设备时区不变性。
