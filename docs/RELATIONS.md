# 干支关系与术语说明

仅做确定性组合匹配，不预测事件。关系表参考公版《三命通会》卷二“论十干合、论支元六合、论支元三合、论六害、论三刑、论冲击”：
https://zh.wikisource.org/wiki/三命通會/卷二

- 天干五合：甲己、乙庚、丙辛、丁壬、戊癸。
- 地支六合：子丑、寅亥、卯戌、辰酉、巳申、午未。
- 地支三合：申子辰、亥卯未、寅午戌、巳酉丑，要求三种支齐全。
- 六冲：子午、丑未、寅申、卯酉、辰戌、巳亥。
- 六害：子未、丑午、寅巳、卯辰、申亥、酉戌。
- 刑：子卯；寅巳申、丑戌未分别标注两支、三支齐全；辰辰、午午、酉酉、亥亥须不同柱位重复。

三刑两支是否即论刑存在流派差异，显示为候选结构而非三支齐全。不采用争议性的吉凶事件断语。只检测明干和地支，不做暗合、半合、旺衰、距离权重、合化判断，不以有合推断已化，也不以多种关系相抵消。

本命内部与岁运参与分组。大运和流年只在两者交集时段配对，沿用上一版半开区间；每次选择都重算。时刻未知或柱位有多个候选时，该柱整体排除并提示，不拼接互斥候选。本命两支关系不会因岁运补齐第三支而从本命分组消失。

术语词典以日干为参照，对照 lunar-typescript 的十神结果解释生克和阴阳同异；正偏不作为吉凶评分。点按、键盘打开原有 Popover 组件，支持 Escape 关闭。
