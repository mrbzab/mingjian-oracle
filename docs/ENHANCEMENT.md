# 八字增强与解读提示词

新增「八字增强 / AI」页签。点击生成后，在浏览器动态加载 mingyu-core 0.2.1（MIT）与 zhiji-bazi 0.2.1（Apache-2.0）。没有远程排盘请求、AI 请求或 API 密钥。

- 命笺继续负责历法、时区、真太阳时、四柱和大运。增强层直接使用已解析四柱，避免两套日期算法混用或重复校正。
- 知己八字根据四柱生成身强弱、格局和用神规则结果；不把它们视作客观预测。
- 发现上游部分用神模板可能声称「原局无某五行」而四柱或藏干实际包含该五行。适配层检查该类明确矛盾，命中时将用神和喜忌标为待复核，不传播矛盾解释；该检查不是对上游所有规则的全面审计。
- 命语负责十神透藏分布和生克链条，保留全部藏干，不以出现次数当作强弱权重。其统计包含日干本身作为比肩，界面明确标注。
- 未知时刻、候选四柱不能生成增强结果。出生资料重新排盘后组件重置，旧分析与提示词不沿用。
- 提示词保留原始命盘、规则、复核提示、算法来源及用户问题。可编辑和复制，不自动发送出生资料。修改问题后需重新生成。
