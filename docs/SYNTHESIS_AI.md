# 综合解读、宫位交互与 AI 追问

- 综合入口使用当前八字和已生成的紫微、奇门快照。紫微快照绑定出生资料及所选年份；资料重排、流派或运限日期变化后旧快照不再纳入。奇门独立，修改起局时刻即失效。
- 大运流年、八字增强与紫微共享关注年份。紫微查询具体日期（跨年份时默认 7 月 1 日），大限/流年信息不代表整段公历年；农历年界与八字立春年界分开标注。
- 宫位侧栏使用可键盘操作的 Sheet。紫微展示索引 0/4/8/6 的三方四正与各层四化落宫；奇门筛选该宫的门、星、神、天地干及经典组合。
- 提示词要求分列来源、支持与相反因素、相同主题与分歧；不把多体系结果当作准确性验证。

## AI

`POST /api/chat` 为固定服务商代理，支持 DeepSeek 与 OpenAI Chat Completions。使用者在页面输入模型 ID 和 API 密钥（BYOK），不使用站点共享密钥、环境变量或持久存储。密钥通过 HTTPS 请求的 JSON 送到本站，在本站作为 Authorization 头转发至固定官方 endpoint，应用代码不记录或保存密钥。非 HTTPS 本地开发仅用于本机预览。

用户点击发送才转发命盘资料及对话，页面明确披露范围与服务商费用。模型输出按普通文本渲染，不执行 HTML。历史保留当前会话最多十轮；不静默截断历史。更换综合提示词后旧对话隔离，旧请求中止。支持停止、重试、清空、手动移除敏感资料。

代理校验 Origin、请求体大小、角色序列、字段长度、模型及密钥字符格式。固定 endpoint 禁止重定向，55 秒超时，输出上限 2000 token，OpenAI `store:false`。错误只返回本地固定提示，不回显上游原始响应或密钥。无密钥时不调用服务商。没有实施长期历史、用户账户或站点付费额度管理。
