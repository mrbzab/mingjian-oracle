# 专题解读与双时辰对照（2026-09-13）

## 算法修正
- 八字及奇门严格校验小时、分钟和秒；拒绝 60 秒，避免 Temporal 自动规范化为 59 秒。
- 岁运年度在出生时刻分段，出生前不生成个人岁运关系。未知时刻使用出生日期的零点作为最低日期边界。
- 时间轴交运标记只比较出生后的大运变化，不把出生边界误标为交运。
- 隐藏出生资料的报告同步遮蔽新增的出生日期分段边界。
- 保持现有 lunar-typescript、mingyu-core、iztro 与 zhiji-bazi 固定版本，不替换经过验证的节气与换日口径。

## 专题综合解读
事业与学习、关系与相处、自我成长。列出相关柱位透干/藏干十神、对应紫微宫位与三方四正，分开列出本命、大限、流年四化。岁运关系按实际适用时段显示。奇门需用户勾选、填写具体问题并提供有效独立起局结果才进入专题提示词。

根据用户要求，不单独展示不确定性说明区。缺失资料仍以状态展示；规则匹配不转写为确定的现实事件。

## 双时辰对照
同一出生日期分别输入两组时刻，沿用当前时区、真太阳时、换日规则和紫微流派。逐项比较四柱、日主、校正时刻、起运方向与时刻、十二宫主辅星与本命四化，以及所选日期大限、流年。支持只看差异、复制、采用候选 A/B；采用后可自行保存档案。输入变化立即清除旧结果，异步旧任务不回填。
